# 인쇄 모드 자동 전환 기능 구현 완료

## 📋 요구사항

사용자 요청:
1. **배경제거 적용 시**: 자동으로 레이아웃 인쇄 모드로 전환
2. **일반인쇄 모드 변경 시**: 원본 이미지만 표시 (배경제거 효과 제거)

## ✅ 구현 완료 내역

### 1. 배경제거 완료 시 자동 모드 전환

#### A. 자동 배경제거 완료 (앞면)
**파일**: `hana_studio.py:1374-1378`

```python
# === 자동으로 레이아웃 인쇄 모드로 전환 ===
if self.print_mode != "layered":
    self.log("[AUTO] 배경제거 완료 → 레이아웃 인쇄 모드로 자동 전환")
    self.ui.components['print_mode_panel'].set_mode("layered")  # UI 업데이트
    self.on_print_mode_changed("layered")  # 내부 상태 업데이트
```

**동작**:
- 앞면 배경제거가 완료되면 자동으로 레이아웃 인쇄 모드로 전환
- 이미 레이아웃 인쇄 모드인 경우 중복 전환하지 않음
- 사용자에게 자동 전환 로그 표시

#### B. 자동 배경제거 완료 (뒷면)
**파일**: `hana_studio.py:1405-1409`

```python
# === 자동으로 레이아웃 인쇄 모드로 전환 ===
if self.print_mode != "layered":

    self.on_print_mode_changed("layered")  # 내부 상태 업데이트
```

**동작**: 앞면과 동일

#### C. 수동 마스킹 업로드 완료
**파일**: `hana_studio.py:1283-1287`

```python

if self.print_mode != "layered":
```

**동작**:

- 앞면/뒷면 모두 동일하게 적용

### 2. 일반인쇄 모드 변경 시 원본 이미지 표시

**파일**: `hana_studio.py:1130-1149`

```python
# === 일반인쇄 모드로 변경 시 원본 이미지만 표시 ===
if mode == "normal":
    self.log("[AUTO] 일반 인쇄 모드 → 원본 이미지로 전환")
    # 앞면 미리보기를 원본 모드로 전환
    front_viewer = self.ui.components['front_unified_mask_viewer']
    if hasattr(front_viewer, 'btn_original'):
        front_viewer.btn_original.setChecked(True)

    # 뒷면 미리보기를 원본 모드로 전환 (양면인 경우)
    if self.is_dual_side:
        back_viewer = self.ui.components['back_unified_mask_viewer']
        if hasattr(back_viewer, 'btn_original'):
            back_viewer.btn_original.setChecked(True)

# 캔버스 미리보기 효과 설명
if mode == "normal":
    canvas_effect = "원본 이미지 (배경제거 효과 없음)"
else:
    canvas_effect = "배경 반투명 (실제 인쇄 결과 시뮬레이션)"
self.log(f"   캔버스 표시: {canvas_effect}")
```

**동작**:
- 일반인쇄 모드로 변경 시 UnifiedMaskViewer의 미리보기 모드를 "원본"으로 자동 전환
- 앞면과 뒷면(양면인 경우) 모두 자동 전환
- 사용자에게 명확한 피드백 제공

## 🎯 사용자 시나리오

### 시나리오 1: 배경제거 → 레이아웃 인쇄 자동 전환

```
1. 사용자: 이미지 업로드
2. 사용자: "AI 배경제거" 버튼 클릭
3. 시스템: 배경제거 완료
4. 시스템: [AUTO] 배경제거 완료 → 레이아웃 인쇄 모드로 자동 전환 ✅
5. 화면: 레이아웃 인쇄 모드 버튼 선택됨
6. 캔버스: 배경 반투명, 마스킹 영역 불투명 표시
```

### 시나리오 2: 일반인쇄 → 원본 이미지 표시

```
1. 사용자: (배경제거가 적용된 상태에서)
2. 사용자: 일반인쇄 모드 선택
3. 시스템: [AUTO] 일반 인쇄 모드 → 원본 이미지로 전환 ✅
4. 캔버스: 원본 이미지만 표시 (배경제거 효과 없음)
5. 로그: "캔버스 표시: 원본 이미지 (배경제거 효과 없음)"
```

### 시나리오 3: 수동 마스킹 → 레이아웃 인쇄 자동 전환

```
1. 사용자: 이미지 업로드
2. 사용자: "수동 마스크" 버튼 클릭 → 마스크 이미지 선택
3. 시스템: 마스킹 업로드 완료
4. 시스템: [AUTO] 마스킹 업로드 완료 → 레이아웃 인쇄 모드로 자동 전환 ✅
5. 화면: 레이아웃 인쇄 모드 버튼 선택됨
```

## 🎨 UI 변화 요약

### 배경제거 완료 시

**Before (수정 전)**:
- 인쇄 모드: 사용자가 선택한 모드 유지
- 캔버스: 선택된 모드에 따라 표시

**After (수정 후)**:
- 인쇄 모드: 자동으로 레이아웃 인쇄로 전환 ✅
- 캔버스: 배경 반투명 + 마스킹 불투명
- 로그: "[AUTO] 배경제거 완료 → 레이아웃 인쇄 모드로 자동 전환"

### 일반인쇄 모드 선택 시

**Before (수정 전)**:
- 캔버스: 이전 미리보기 모드 유지 (겹침 모드일 수 있음)
- 배경: 원본 그대로 표시 (이전 수정으로)

**After (수정 후)**:
- 캔버스: 자동으로 "원본" 미리보기 모드로 전환 ✅
- 배경: 원본 이미지만 표시 (배경제거 효과 완전히 제거)
- 로그: "[AUTO] 일반 인쇄 모드 → 원본 이미지로 전환"
- 로그: "캔버스 표시: 원본 이미지 (배경제거 효과 없음)"

## 💡 핵심 개선사항

### 1. 사용자 경험 향상
- **자동화**: 사용자가 수동으로 모드를 전환할 필요 없음
- **명확성**: 배경제거 = 레이아웃 인쇄, 일반인쇄 = 원본 이미지로 명확히 연결
- **직관성**: 캔버스에 표시되는 것이 정확히 인쇄되는 것

### 2. 오류 방지
- 일반인쇄 모드에서 배경이 연하게 인쇄되는 문제 완전 해결
- 사용자가 잘못된 모드로 인쇄하는 실수 방지

### 3. 로그 개선
- 자동 전환 시 명확한 피드백 제공
- 캔버스 표시 방식에 대한 설명 추가

## 📝 사용자 가이드

### 배경제거를 사용하는 경우

1. **이미지 업로드**
2. **"AI 배경제거" 또는 "수동 마스크" 선택**
3. **시스템이 자동으로 레이아웃 인쇄 모드로 전환** ← 자동!
4. 캔버스에서 배경이 반투명하게 표시됨 (실제 인쇄 결과)
5. 인쇄 실행 → 마스킹 영역은 선명하게, 배경은 반투명하게 인쇄

### 원본 이미지를 그대로 인쇄하는 경우

1. **이미지 업로드**
2. **일반인쇄 모드 선택** (또는 기본값 유지)
3. **시스템이 자동으로 원본 이미지만 표시** ← 자동!
4. 캔버스에서 원본 이미지가 정상적으로 표시됨
5. 인쇄 실행 → 원본 이미지가 그대로 인쇄

### 모드 전환

- **배경제거 후 → 일반인쇄로 전환**: 원본 이미지만 표시됨
- **일반인쇄 → 레이아웃 인쇄로 전환**: 배경 반투명 효과 표시
- **언제든지 수동으로 모드 전환 가능**
