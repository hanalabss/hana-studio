# 레이어 인쇄 시각적 가이드 (Layer Printing Visual Guide)

## 📊 현재 문제 시각화

### ❌ 잘못된 현재 방식

```
┌─────────────────────────────────────────┐
│  1단계: 캔버스 준비                      │
│  ┌───────────────────────────────────┐  │
│  │  빈 캔버스 (흰색)                  │  │
│  └───────────────────────────────────┘  │
└─────────────────────────────────────────┘

            ↓ draw_watermark(mask_path)

┌─────────────────────────────────────────┐
│  2단계: 마스크 그리기                    │
│  ┌───────────────────────────────────┐  │
│  │  ████ ← 검은색 (객체)             │  │
│  │  ░░░░ ← 흰색 (배경)               │  │
│  └───────────────────────────────────┘  │
└─────────────────────────────────────────┘

            ↓ draw_image(original_path)

┌─────────────────────────────────────────┐
│  3단계: 원본 이미지 위에 겹쳐 그리기     │
│  ┌───────────────────────────────────┐  │
│  │  ████ + 🔴🟢🔵 = 🟤 (어두운 색)   │  │
│  │  ░░░░ + 🔴🟢🔵 = 🔴🟢🔵 (정상)   │  │
│  └───────────────────────────────────┘  │
│                                          │
│  ⚠️ 문제: 검은색과 원본 색상이 겹침!    │
└─────────────────────────────────────────┘

            ↓ R600PrintDraw()

┌─────────────────────────────────────────┐
│  4단계: 프린터로 전송                    │
│  결과: 색상이 이상함! 🟤❌              │
└─────────────────────────────────────────┘
```

## 🔄 마스크 반전의 필요성

### 현재 마스크 형식

```
┌─────────────────────────────────────┐
│  AI 배경제거 결과 마스크             │
│  ┌───────────────────────────────┐  │
│  │  ████████ ← 검은색 (객체)     │  │
│  │  ░░░░░░░░ ← 흰색 (배경)       │  │
│  └───────────────────────────────┘  │
│                                      │
│  의미:                               │
│  - 검은색 = 불투명하게 하고 싶은 부분│
│  - 흰색   = 반투명하게 하고 싶은 부분│
└─────────────────────────────────────┘
```

### 프린터 워터마크 해석

```
┌─────────────────────────────────────┐
│  draw_watermark() 함수 해석          │
│  ┌───────────────────────────────┐  │
│  │  ████████ ← 어두운 부분        │  │
│  │          → W 레이어 없음 ❌    │  │
│  │                                │  │
│  │  ░░░░░░░░ ← 밝은 부분          │  │
│  │          → W 레이어 인쇄 ✅    │  │
│  └───────────────────────────────┘  │
│                                      │
│  의미:                               │
│  - 밝은 부분 = W 레이어로 인쇄       │
│  - 어두운 부분 = W 레이어 없음       │
└─────────────────────────────────────┘
```

### ⚠️ 불일치!

```
우리가 원하는 것:          프린터가 해석하는 것:
┌─────────────────┐      ┌─────────────────┐
│ ████ = 불투명   │      │ ████ = 반투명   │
│ ░░░░ = 반투명   │  ≠   │ ░░░░ = 불투명   │
└─────────────────┘      └─────────────────┘

        ⚠️ 반대로 해석됨!
```

### ✅ 해결책: 마스크 반전

```
1단계: 원본 마스크
┌─────────────────┐
│ ████ (검은색)   │
│ ░░░░ (흰색)     │
└─────────────────┘

    ↓ cv2.bitwise_not()

2단계: 반전된 마스크
┌─────────────────┐
│ ░░░░ (흰색)     │ ← 이제 프린터가 W 레이어로 인쇄
│ ████ (검은색)   │ ← 이제 W 레이어 없음
└─────────────────┘

    ↓ draw_watermark(반전된 마스크)

3단계: 프린터 해석
┌─────────────────────────────┐
│ ░░░░ = W 레이어 인쇄 = 불투명│ ✅
│ ████ = W 레이어 없음 = 반투명│ ✅
└─────────────────────────────┘
```

### 변경 전 (Before)

```python
def prepare_front_canvas(self, front_image_path, watermark_path, ...):
    self.setup_canvas(card_orientation)

    # ❌ 문제: 마스크를 그대로 사용
    if watermark_path:
        self.draw_watermark(0.0, 0.0, card_width, card_height, watermark_path)
        #                                                       ^^^^^^^^^^^^
        #                                   검은색(객체) / 흰색(배경) 그대로

    self.draw_image(0.0, 0.0, card_width, card_height, front_image_path)

    return self.commit_canvas()
```

### 변경 후 (After)

```python
def prepare_mask_for_watermark(self, mask_path):
    """마스크 반전: 검은색 ↔ 흰색"""
    import cv2
    from utils.safe_temp_path import create_safe_temp_file

    mask = cv2.imread(mask_path)
    inverted = cv2.bitwise_not(mask)  # ✅ 반전!

    inverted_path = create_safe_temp_file(prefix="watermark_inv", suffix=".jpg")
    cv2.imwrite(inverted_path, inverted, [cv2.IMWRITE_JPEG_QUALITY, 95])

    return inverted_path

def prepare_front_canvas(self, front_image_path, watermark_path, ...):
    self.setup_canvas(card_orientation)

    # ✅ 수정: 마스크를 반전시켜서 사용
    if watermark_path:
        inverted_watermark = self.prepare_mask_for_watermark(watermark_path)
        self.draw_watermark(0.0, 0.0, card_width, card_height, inverted_watermark)
        #                                                       ^^^^^^^^^^^^^^^^^
        #                                   흰색(객체) / 검은색(배경) 반전됨!

    self.draw_image(0.0, 0.0, card_width, card_height, front_image_path)

    return self.commit_canvas()
```

## 🎨 레이어별 결과 시뮬레이션

### 일반 인쇄 (Normal Mode)

```
┌────────────────────────────────────────┐
│  draw_image(원본)만 사용                │
│  ┌──────────────────────────────────┐  │
│  │  🔴🟢🔵 원본 이미지 전체         │  │
│  │  → YMC 레이어만 인쇄             │  │
│  │  → 전체가 반투명                 │  │
│  └──────────────────────────────────┘  │
└────────────────────────────────────────┘
```

### 레이어 인쇄 (Layered Mode) - 수정 전 ❌

```
┌────────────────────────────────────────┐
│  draw_watermark(마스크) + draw_image   │
│  ┌──────────────────────────────────┐  │
│  │  검은색 + 🔴 = 🟤 (어두운 빨강)  │  │ ❌
│  │  흰색   + 🔴 = 🔴 (정상 빨강)    │  │ ✅
│  └──────────────────────────────────┘  │
│                                         │
│  문제: 객체 부분 색상이 어두워짐!      │
└────────────────────────────────────────┘
```

### 레이어 인쇄 (Layered Mode) - 수정 후 ✅

```
┌────────────────────────────────────────┐
│  draw_watermark(반전 마스크) + image   │
│  ┌──────────────────────────────────┐  │
│  │  W + 🔴 = 🔴 (불투명 빨강)       │  │ ✅
│  │      🔴 = 🔴 (반투명 빨강)       │  │ ✅
│  └──────────────────────────────────┘  │
│                                         │
│  결과: 객체는 불투명, 배경은 반투명!   │
│        색상 모두 정확함! ✨            │
└────────────────────────────────────────┘
```

## 🔍 추가 디버깅 가이드

### 문제가 지속될 경우 확인할 사항

1. **마스크 이미지 확인**
   ```python
   # 반전 전 마스크
   cv2.imshow("Original Mask", cv2.imread(mask_path))

   # 반전 후 마스크
   inverted = cv2.bitwise_not(cv2.imread(mask_path))
   cv2.imshow("Inverted Mask", inverted)
   ```

2. **프린터 DLL 로그 확인**
   - draw_watermark() 호출 시 반환값 확인
   - draw_image() 호출 시 반환값 확인
   - 모두 0이면 성공

3. **실제 인쇄 결과 촬영**
   - 객체 부분과 배경 부분 색상 비교
   - 반투명/불투명 차이 육안 확인

4. **예전 프로그램과 비교**
   - 예전 프로그램의 마스크 이미지 확인
   - 반전 여부 비교
